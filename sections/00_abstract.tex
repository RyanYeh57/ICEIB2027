\begin{abstract}
Finding a nearby waste collection point is only the first step for a resident who must meet a moving collection vehicle. The resident also needs to know whether there is enough time to walk there. This course project proposes GarbageGo, a decision-support application for Taichung that combines collection schedules, vehicle observations, pedestrian routes, and an allowance for uncertainty. Its recommendation compares the remaining time until a truck is expected with the user's walking time and a safety buffer. A language-model interface is planned to translate user requests into tool queries and explain the resulting options. An existing project audit of the municipal open data recorded 980,775 distinct vehicle observations over approximately 29 days and examined vehicle identifier overlap and address matching. These findings inform the system design and identify constraints on data freshness and location accuracy. The project presents a proposed workflow and data analysis, with performance evaluation left for subsequent implementation.
\end{abstract}
